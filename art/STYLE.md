# The Unfolding: art direction

The look is a **stylized hero-shooter rendered in a No Man's Sky-scale universe**. Think readable silhouettes, clean color blocking, soft painterly light and big, vivid alien skies. Everything is original. Nothing is copied from any game, film or brand.

## Principles

1. **Silhouette first.** Every asset must read at a glance from 30 m away. Use chunky, slightly exaggerated proportions and no noisy micro-detail.
2. **Color blocking, not textures.** Use solid material colors, with vertex colors used only as grayscale ambient occlusion and soft vertical gradients (white = full color). No image textures.
3. **Bevel the hard edges.** Hard-surface pieces get a small bevel (2–4% of the object's size, 1–2 segments) so the light catches the edges. Organic forms are smooth-shaded and subdivided.
4. **Few, deliberate accents.** Each asset gets one or two accent colors at most. Emissive "glow" is reserved for meaning: visors, beacons, energy, bioluminescence.
5. **Painterly variation.** Avoid perfect symmetry and uniform scale. Rocks lean, canopies clump, and crystals vary in height.

## Technical conventions

- Units are meters. Blender +Z is up and the model faces **-Y** in Blender, which becomes +Z forward and +Y up in glTF/three.js.
- Origins: props sit at the base center where they touch the ground. Characters and ships use the origin at the feet or ground contact.
- Export GLB with modifiers applied, no textures and no cameras or lights. Use `COLOR_0` vertex colors (grayscale AO/gradient) where helpful.
- **Material slot names are the contract.** The game replaces glTF materials by name with per-world stylized materials, so the GLB colors are only defaults:
  - Flora and props: `Rock`, `RockDark`, `Bark`, `Leaf`, `LeafAlt`, `Grass`, `Petal`, `Crystal`, `Glow`, `Sand`, `Metal`, `Stone`, `Trim`
  - Ship: `Hull`, `HullDark`, `Accent`, `Glass`, `Glow`, `Metal`
  - Agent: `Suit`, `SuitDark`, `Fabric`, `Accent`, `Visor`, `Glow`, `Metal`, `Rubber`
  - Landmarks: `Stone`, `StoneDark`, `Trim`, `Accent`, `Glow`, `Metal`, `Glass`
- Collision proxies inside landmark GLBs are invisible meshes named `COL_BOX_*` (oriented box), `COL_CYL_*` (vertical cylinder) or `COL_SPH_*` (sphere). Interaction points are empties named `POI_<id>`.
- Triangle budgets: grass tuft ≤ 24, small plant ≤ 120, rock ≤ 200, tree ≤ 700, landmark ≤ 15k, agent ≤ 25k, ship ≤ 12k.

## Pipeline

All art is generated by the Python scripts in `art/blender/`, which run headless in Blender 5 (`bpy`). Outputs go to `public/models/`. Each script is deterministic, so you can rerun it after tweaking a parameter. GLBs are optimized with `gltfpack -cc` (meshopt), and the game decodes them with three.js's bundled `MeshoptDecoder`.
